# 知华 TestAgent · AI 软件测试智能体


## 本次升级：隔离不稳定测试后的有效覆盖

将稳定通过、失败和隔离不稳定测试按互斥口径核对，计算有效通过率，关键需求不能只靠隔离用例覆盖。

新增已认证的结构化录入工作台（`/operations.html`），支持批量核算、逐条结果依据、分级复核和CSV/完整JSON导出。结果由真实后端算法计算，不是预置演示数字。所有数值精确传递，不调用外部模型。

这是**只读核算**：不写库、不审批、不自动执行财务、签署、销毁或设备控制。输入条件满足不是执行授权。[算法、输入边界与接口说明](docs/OPERATIONS-REVIEW.md)。
## 本次功能更新：需求测试证据矩阵

把需求与实际测试结果逐项关联，区分未覆盖、失败、阻塞、未执行和通过；拒绝未知需求引用，不能以用例数量替代通过证据。 登录后从「业务计算工具」进入，支持真实后端校验与结果导出。详见[接口、示例与边界说明](docs/AI_BUSINESS_UPGRADE_20261023.md)。本次不改变既有许可及联系方式。

## 一次发布在这里如何流转

```text
代码变更 → 风险识别 → 测试套件生成 → 并行执行 → 质量门禁 → 发布证据
```

`POST /api/ai/testing/design` 会依据变更风险、文件数量、关键流程、当前覆盖率、不稳定用例、数据库变更和线上事故生成优先级、用例数、目标覆盖率、测试套件及发布门禁。

![TestAgent 发布质量驾驶舱](docs/images/testagent-admin.png)

管理端聚焦发布组合、覆盖率、执行器负载、P0/P1 阻断和人工审批。

![TestAgent 测试工程师 H5](docs/images/testagent-h5.png)

工程师端用于执行回归、提交失败证据、查看环境状态和升级质量风险。

## 输入对照与版本化快照

在既有「隔离不稳定测试后的有效覆盖」基础上，新增 `/comparison.html`：基准与候选两组数据都由当前真实算法重算，按编号展示新增、移除、逐字段变化和精确数值差，支持筛选、分页和全量导出。原核算入口可导出输入快照，对照页经后端完整校验后整体导入；失败不覆盖当前输入。

快照区分项目、字段契约及算法版本。建议较宽松不代表风险已下降，输入摘要不是签名；操作人和时间仅为响应元数据，不是持久化审计。本次未新增模型调用或业务写入，也不代表全系统生产认证。详见[输入对照操作与接口说明](docs/INPUT-COMPARISON.md)。
